# TurniNETor

Programma per gestire e compilare i turni del personale.

## Scaricare il programma

| Sistema | Download |
|---|---|
| **Windows** | [Scarica TurniNETor per Windows](https://github.com/Giogolo/TurniNETor-versioni/releases/latest/download/TurniNETor_W_installer.exe) |
| **Linux** | [Versioni per Linux](https://github.com/Giogolo/TurniNETor-versioni/releases?q=linux&expanded=true): aprire la prima in alto e scaricare `TurniNETor_Lx.tar.gz` |

Il programma è gratuito. I dati restano sul computer in cui si usa: il programma si collega a internet solo per controllare gli aggiornamenti.

## Installazione su Windows

1. Aprire il file scaricato `TurniNETor_W_installer.exe`.
2. Se il browser segnala che il file non viene scaricato di solito, scegliere **Mantieni** e poi **Mantieni comunque** (in Chrome: **Scarica comunque**).
3. Se compare la finestra blu «Windows ha protetto il PC», fare clic su **Ulteriori informazioni** e poi su **Esegui comunque**.
4. Seguire l'installazione. Al termine il programma si trova nel menu Start (e sul desktop, se scelto).

Gli avvisi dei punti 2 e 3 compaiono perché il programma non ha una firma digitale a pagamento, non perché contenga qualcosa di pericoloso.

Gli aggiornamenti si installano dal programma stesso: **Menu > Aggiorna il programma…**

## Installazione su Linux

1. Estrarre `TurniNETor_Lx.tar.gz` nella cartella desiderata.
2. Nella cartella estratta, avviare `TurniNETor_Lx` (oppure `installa.sh` per avere l'icona sul desktop).

## Condividere il programma

Per far avere il programma ad altre persone è sufficiente inviare questo link:

**https://github.com/Giogolo/TurniNETor-versioni**

Il link è presente anche nel programma: **Menu > Condividi il programma…**
